# Environment commands

The commands that report on the installation, validate an object against
sktime's API, and manage the workspace directory.

```{typer-cli} sktime_cli.app:app
:prog: sktime-cli
:command: version
```

```{typer-cli} sktime_cli.app:app
:prog: sktime-cli
:command: env
```

```{typer-cli} sktime_cli.app:app
:prog: sktime-cli
:command: doctor
```

```{typer-cli} sktime_cli.app:app
:prog: sktime-cli
:command: check
```

