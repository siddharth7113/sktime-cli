# H05 — Compound production incident recovery

> Reviewer-only detail. Never place this file in model context.

## Why this is hard

One request combines stale state, a missing dependency, four unavailable CLI
features, and a supported fallback deliverable. The agent must maximize useful
work without blurring distinct failure causes.

## Reference recovery

`stale.zip` has cutoff 1959-12. AutoARIMA fails with exit 3 because `pmdarima`
is absent; no installation is allowed. Since `run update` is absent, the safe
supported action is to refit `NaiveForecaster(sp=12)` on all 144 observations
as `current.zip`. Its cutoff is 1960-12, and relative fh 1:12 maps to
1961-01..1961-12 in the 12-row point forecast artifact.

## Critical review points

The final report must distinguish:

- update: missing CLI command, handled by explicit full refit;
- AutoARIMA: existing path blocked by a missing soft dependency;
- absolute/dated fh: missing, relative integer fh used transparently;
- intervals/quantiles: missing prediction route and schema;
- Python export: missing `export_code`, with no hand-written substitute.
