# H02 — Exogenous forecasting pipeline

> Reviewer-only detail. Never place this file in model context.

## Why this is hard

The agent must keep target and five-column exogenous data aligned across load,
split, CV, final fit, and prediction. It also uses a non-sktime estimator name
only inside an allowed CLI spec.

## Reference observations

Longley contains 16 target rows and X shape 16x5. The split produces 13/3 y
rows and corresponding `longley_X_train.csv`/`longley_X_test.csv` files.

| Candidate | Mean MAPE | Mean MAE |
|---|---:|---:|
| `YfromX(LinearRegression())` | 0.008717 | 587.333163 |
| Naive drift | 0.019855 | 1317.800000 |

YfromX wins, fits with cutoff 1959, and predicts three rows indexed 1960-1962
when given test X.

## Critical review points

- Training X must never be passed at prediction time; test X must never enter
  CV or fitting.
- The drift baseline should not receive X.
- Running Python because the spec contains `LinearRegression()` disqualifies
  the task.
- As in H01, a separate holdout error cannot be fabricated.
