# H04 — Artifact reproduction and nested mutation

> Reviewer-only detail. Never place this file in model context.

## Why this is hard

The agent reverse-engineers a fitted composition, reuses the emitted spec,
changes a nested component without rewriting that spec, and compares three
prediction arrays.

## Reference observations

All artifacts are `TransformedTargetForecaster` models with cutoff 1960-12.
Production and reproduction contain ExponentTransformer power 0.5 and
NaiveForecaster sp=12. Their 1961-01..1961-06 values match exactly:
417, 391, 419, 461, 472, 535.

The variant must be produced with `--set NaiveForecaster__sp=4`; its values are
508, 461, 390, 432, 508, 461.

## Critical review points

- The recovered spec must come from the artifact, not from benchmark setup
  knowledge.
- The original spec literal is reused for both new fits.
- The nested parameter must be verified through model inspection.
- `model inspect --spec --json` emits plain text, which should be recorded as
  an output-contract inconsistency rather than parsed as JSON.
