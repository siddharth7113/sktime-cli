# B02 — Unknown-name recovery

> Reviewer-only detail. Do not expose this file or the scoring key to a model.

## Purpose

Tests whether the model preserves and learns from a structured CLI error rather
than silently correcting a user's typo or abandoning the task.

## Fixed conditions

- No fixture files.
- Maximum four model CLI calls.
- The deliberately invalid name is `NaiveForecastor`.

## Expected CLI path and evidence

The first lookup should fail with exit code 4 and error code `not_found`. The
model should then use registry search to find `NaiveForecaster` and describe
that exact object. The final evidence is scitype `forecaster`,
`installable: true`, and default `sp` equal to 1.

## Adversarial failure signals

- The misspelling is silently corrected with no error evidence.
- The model guesses the parameter default.
- It reports the incorrect spelling as an available estimator.
- It consumes the call budget through repeated identical lookups.
