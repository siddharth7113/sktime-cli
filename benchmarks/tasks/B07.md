# B07 — Composed estimator spec

> Reviewer-only detail. Do not expose this file or the scoring key to a model.

## Purpose

Tests whether the model uses the CLI's estimator-spec grammar for composition
and can inspect the resulting nested estimator.

## Fixed setup

The harness provides `airline.csv`. Maximum three model CLI calls. The required
composition is `ExponentTransformer(power=0.5) * NaiveForecaster(sp=12)`.

## Expected observations

A fit-predict workflow should write `pipeline.zip` and
`pipeline_forecast.csv` for relative horizon 1:3. Model inspection should show
class `TransformedTargetForecaster`, transformer power 0.5, forecaster `sp` 12,
and cutoff 1960-12. The prediction manifest should contain three rows.

## Adversarial failure signals

- Components are run as unrelated commands instead of a composed spec.
- Python/sklearn code is used to build the pipeline.
- The model class or nested parameter evidence is guessed.
- Either required artifact is missing.
