# B01 — Capability-aware discovery

> Reviewer-only detail. Do not expose this file or the scoring key to a model.

## Purpose

Tests whether the model can translate a capability request into registry tag
filters instead of naming familiar estimators from memory.

## Fixed conditions

- No fixture files.
- Maximum two model CLI calls.
- Only estimators installed in the locked benchmark environment qualify.

## Expected CLI path and evidence

The model should search the `forecaster` scitype with
`capability:missing_values=true`, restrict results with `--installable-only`,
request the capability tag as an output column, and limit the result to three.
Every call must use `--json`.

The reference environment currently returns BaggingForecaster,
DirRecTabularRegressionForecaster, and DirRecTimeSeriesRegressionForecaster,
including module names, `installable: true`, and the requested capability tag.

## Adversarial failure signals

- Names are guessed without a registry result.
- Search results are not limited to forecasters or installed objects.
- Missing-value support is asserted without a filter/tag as evidence.
- More or fewer than three results are reported.
