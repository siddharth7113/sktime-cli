# B06 — Panel classification probabilities

> Reviewer-only detail. Do not expose this file or the scoring key to a model.

## Purpose

Tests panel-data handling, classifier artifacts, probability prediction, and
inspection of a generated result file.

## Fixed setup

The harness provides the built-in classification panel as `unit_test.ts`.
Maximum three model CLI calls.

## Expected observations

The model should fit `DummyClassifier()` to `classifier.zip`, then predict with
`--proba` into `probabilities.csv`. CLI output and inspection should establish
scitype `classifier`, 42 prediction rows, probability columns `1` and `2`, and
no missing values.

This is intentionally an in-sample mechanics test; the model should not claim
that it measures generalization performance.

## Adversarial failure signals

- Class labels are produced instead of probabilities.
- The `.ts` panel is treated as a forecasting series.
- Training-set predictions are described as an honest accuracy evaluation.
- The CSV is opened with a non-CLI tool.
