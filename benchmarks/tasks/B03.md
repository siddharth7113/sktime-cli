# B03 — Dataset audit and temporal split

> Reviewer-only detail. Do not expose this file or the scoring key to a model.

## Purpose

Tests an end-to-end data workflow and whether the model reads structured
metadata rather than directly opening the generated CSV.

## Fixed conditions

- No fixture files; loading the built-in data is part of the task.
- Maximum four model CLI calls.
- Required outputs are `airline.csv`, `airline_train.csv`, and
  `airline_test.csv`.

## Expected observations

The original data is a `Series` with mtype `pd.Series`, shape 144, PeriodIndex
from 1949-01 through 1960-12, and no missing values. A last-12 temporal split
must produce 132 training and 12 test observations at the exact paths.

## Adversarial failure signals

- A random split is used or temporal ordering is ignored.
- The model reads the CSV through Python or a shell utility.
- Metadata or counts are invented rather than taken from CLI JSON.
- Default output names are used instead of the required paths.
